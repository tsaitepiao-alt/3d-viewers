## 一、設計理念

| 原則 | 說明 |
|---|---|
| 聽得到 | 雙麥克風陣列，3–5 公尺遠場收音 |
| 說得清 | 40mm 喇叭 3W，語速慢、音量足 |
| 看得見 | 7 吋觸控主螢幕 ＋ LED 點陣輔助面板 |
| 按得到 | 60mm 超大緊急按鈕，不用看也摸得到 |
| 不複雜 | 沒有選單、沒有設定頁，只有「講話」和「叫人」 |

**核心判斷**：老人系統的價值在「聽得到、說得清」，不是「螢幕漂亮」。
LED 點陣是加分項，不是主介面。

## 二、系統架構

```
                    ┌──────────────────────────────┐
                    │      12V 3A 電源適配器        │
                    └──────────────┬───────────────┘
                                   │ 12V
                    ┌──────────────▼───────────────┐
                    │   降壓模組 12V→5V 5A          │
                    └──────────────┬───────────────┘
                                   │ 5V
              ┌────────────────────┼────────────────────┐
              │                    │                    │
     ┌────────▼────────┐  ┌────────▼────────┐  ┌───────▼────────┐
     │  Raspberry Pi    │  │  ESP32-C3       │  │  PAM8403       │
     │  Zero 2W         │  │  (LED 點陣驅動)  │  │  音訊放大器     │
     │  (主控)          │  │                 │  │                │
     └───┬────┬────┬───┘  └────────┬────────┘  └───────┬────────┘
         │    │    │               │                    │
     HDMI│  USB│  GPIO│           HUB75              40mm 喇叭
         │    │    │               │                    │
   ┌─────▼──┐ │ ┌──▼──────────┐ ┌──▼─────────────┐     │
   │7吋觸控  │ │ │緊急按鈕 60mm │ │LED 點陣 64×32   │     │
   │螢幕     │ │ │(GPIO+中斷)   │ │P5 面板          │     │
   └────────┘ │ └──────────────┘ └────────────────┘     │
              │                                        │
       ┌──────▼───────┐                        ┌───────▼────────┐
       │ USB 音效卡    │                        │  3W 輸出        │
       │ + 2×INMP441  │                        └────────────────┘
       │ (I2S 麥克風)  │
       └──────────────┘
```

### 為什麼要兩顆 MCU
- **Pi Zero 2W** 跑 UI、語音辨識、TTS、網路 —— 但它驅動 HUB75 點陣很吃力（會掉幀、CPU 滿載）
- **ESP32-C3** 專門驅動 LED 點陣，透過 UART 接收 Pi 的文字指令 → 顯示大字
- 好處：點陣更新不掉幀，Pi 的 CPU 留給語音

## 三、機構設計（3D 列印）

### 外觀尺寸
- **寬 200 × 深 150 × 高 95 mm**
- 正面後傾 **12°**（螢幕面向坐著的老人）
- 圓角 **R8**
- 壁厚 **2.5 mm**

### 分件（5 個可列印件）

| 編號 | 件名 | 尺寸 (mm) | 材料 | 列印時間 |
|---|---|---|---|---|
| 01 | 主機殼 | 200×150×95，壁厚 2.5 | PLA+ 或 PETG，奶油白 | 約 9 小時 |
| 02 | 前框 | 165×105×6，開 154×86 視窗 | PLA+，深墨 | 約 1.5 小時 |
| 03 | 緊急按鈕座 | Ø66×20 | PETG，紅色 | 約 1 小時 |
| 04 | 麥克風座 ×2 | 22×17×6 | PLA+ | 約 20 分 |
| 05 | 底座 | 200×150×8，含 4 個 Ø12×3 凹槽 | PLA+ | 約 2 小時 |

**線材估算**：約 **180 g**（PLA+ 一捲 1kg ≈ NT$300 → 成本約 **NT$55**）

### 組裝順序
1. 底座放平 → 鎖 4 個防滑墊
2. 主機殼套上底座（4 顆 M3×10 自攻）
3. 裝樹莓派（銅柱 M2.5×8，4 顆）
4. 貼散熱片到 Pi
5. 喇叭鎖進側面開孔（2 顆 M3×8）
6. 麥克風座 ×2 裝到正面左右（間距 90mm）
7. 緊急按鈕座裝正面右下 → 鎖按鈕
8. LED 點陣裝正面下緣（4 顆 M2.5×6）
9. 接線（見第五節）
10. 前框卡上（4 個卡扣）
11. 螢幕鎖進前框（4 顆 M2×6）
12. 貼黃銅飾條

## 五、接線表

### 電源
```
12V 3A ──┬── LM2596 IN+
         └── （未來擴充）
GND    ──┬── LM2596 IN-
LM2596 OUT+ (5V) ──┬── Pi Zero 2W (5V pin / USB)
                   ├── ESP32-C3 (5V)
                   ├── LED 點陣 (5V, 需 ≥3A)
                   └── PAM8403 (5V)
LM2596 OUT- (GND) ── 全部共地
```

### 麥克風（I2S → USB 音效卡）
| INMP441 | USB 音效卡 |
|---|---|
| VDD | 3.3V |
| GND | GND |
| SCK | 音效卡類比輸入 L |
| WS | 音效卡類比輸入 R |
| SD | 音效卡接地（屏蔽） |

> 實務建議：直接用 **USB 雙麥克風音效卡**（NT$250）取代 INMP441，省掉 I2S 接線與驅動問題。

### 緊急按鈕
| 按鈕 | Pi Zero 2W |
|---|---|
| NO 一端 | GPIO 17 (pin 11) |
| NO 另一端 | GND (pin 6) |
| | 啟用內部上拉，下降緣觸發 |

### LED 點陣（ESP32-C3 → HUB75）
| HUB75 | ESP32-C3 |
|---|---|
| R1/G1/B1/R2/G2/B2 | GPIO 4/5/6/7/8/9 |
| A/B/C/D/E | GPIO 10/11/12/13/14 |
| CLK | GPIO 15 |
| LAT | GPIO 16 |
| OE | GPIO 17 |
| GND | GND（共 6 條，全部要接） |

ESP32 端用 `ESP32-HUB75-MatrixPanel-DMA` 函式庫。
UART 從 Pi 接收指令：`TEXT|08:30`、`FACE|HAPPY`、`CLEAR`。

## 六、軟體架構

```
┌─────────────────────────────────────────────┐
│  Pi Zero 2W                                  │
│                                              │
│  ┌────────────┐   ┌──────────────────────┐  │
│  │ 主 UI       │   │ 語音管線              │  │
│  │ (Qt/Kivy   │   │                      │  │
│  │  或 Chromium│   │ ① VAD 偵測有人說話   │  │
│  │  kiosk)    │   │ ② faster-whisper STT │  │
│  └─────┬──────┘   │ ③ LLM 回應生成       │  │
│        │          │ ④ TTS 合成           │  │
│        │          └───────┬──────────────┘  │
│        │                  │                 │
│  ┌─────▼──────────────────▼──────────────┐  │
│  │ 對話管理 / 安全規則引擎                 │  │
│  └─────┬──────────────────┬──────────────┘  │
│        │                  │                 │
│  GPIO  │                  │ UART            │
│  → 緊急按鈕               → ESP32（點陣）    │
└────────┼──────────────────┼─────────────────┘
         │                  │
    家屬通知            大字顯示
```

### 語音（沿用已建置的資產）
- **STT**：`faster-whisper` small/medium（本機，`~/.hermes/venvs/whisper/`）
- **TTS 國語**：macOS `say -v Meijia -r 115`（慢速、清楚）
- **TTS 台語**：`~/.hermes/scripts/taigi_tts.py`（媠聲 API，3 句/分限制）
- **LLM**：可走本地小模型或 API（需評估離線需求）

### 安全規則引擎（紅線，不可繞過）
```python
DANGER_KEYWORDS = ["跌倒", "摔倒", "不舒服", "流血", "胸口痛",
                   "喘不過氣", "頭暈", "送醫", "急診"]

if any(k in user_text for k in DANGER_KEYWORDS):
    notify_family()          # 立刻通知家屬（LINE/電話/SMS）
    speak("我已經通知家人了，你坐著不要動。")
    # 不繼續閒聊，不給醫療建議
```

**其他硬規則**
- 麥克風有**實體斷電開關**（硬體切斷，不是軟體靜音）
- 家屬姓名／地址／病歷**絕不傳中國雲端**
- 不主動推銷、不聊投資、不談政治
- 每次對話結束**不保存錄音**，只保存文字摘要（可關閉）

## 七、LED 點陣顯示規格

| 場景 | 顯示內容 | 顏色 |
|---|---|---|
| 待機 | 大字時鐘 `08:30` | 暖白 |
| 整點 | 時間 ＋ 日期 `10/21 週三` | 暖白 |
| 吃藥 | `吃藥` ＋ 閃爍 | 紅色 |
| 聽懂 | 表情 `^_^` / 愛心 | 萊姆綠 |
| 聽不懂 | 問號 `?` | 黃 |
| 緊急 | `已通知家人` | 紅色閃爍 |

解析度 64×32 點 → 字高最大可到 **30 點 ≈ 15cm**（P5 間距）→ 3 公尺外可讀。

## 九、待決問題

1. **離線 vs 雲端**：LLM 要跑本機（Pi Zero 2W 跑不動）還是走 API？
   → 建議 Pi 只做 STT/TTS，LLM 走 API；或改用 Pi 4/5
2. **台語比例**：長輩主要說台語還是國語？影響 TTS 選擇與授權
3. **家屬通知方式**：LINE Notify（已停用）/ Telegram / 電話 / SMS？
4. **供電**：要不要內建電池（停電仍可通話）？
5. **音量**：3W 是否足夠？建議實測後再定
