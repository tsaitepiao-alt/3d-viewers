貓叫聲翻譯機 · 基地台

用 Waveshare RP2350-Touch-AMOLED-1.64 當桌面基地台，負責顯示與觸控。
這塊板子沒有 WiFi/BT（官方規格確認），所以另外串一顆 ESP32-C3 只做無線。兩顆都是 3.3V 邏輯，直接接。

① 系統架構

訊號是單向為主（項圈 → 基地台），回向只有控制指令（改靈敏度／靜音／校準）。

② 為什麼要兩顆

元件負責為什麼不是它單獨做
RP2350 這塊螢幕、觸控、UI、SD 儲存、音訊分析完全沒有 WiFi 也沒有藍牙，碰不到手機或項圈
ESP32-C3BLE 收項圈事件、WiFi 上傳不用它跑螢幕——它沒有那麼多腳位與算力做 LVGL
✅ 好消息：不用電平轉換。
RP2350 的 I/O 是 3.3V，ESP32-C3 的 I/O 也是 3.3V，UART 直接對接即可。（如果是 5V 的 Arduino 就要加轉換）

③ 實際接線：只有 4 條線

RP2350 基地台ESP32-C3說明
GP16（UART0 TX）→GPIO20（RXD）基地台送指令給 C3
GP17（UART0 RX）←GPIO21（TXD）C3 送資料給基地台
3V3→3V3供電（見下方警告）
GND—GND一定要共地，否則 UART 亂碼
⚠️ TX/RX 一定要交叉。TX 接 TX 是新手最常犯的錯，症狀是「完全沒反應」而不是報錯，很難查。

④ 供電：三個一定要知道的坑

坑 1：「5V」腳是 USB 的 VBUS，不是升壓出來的 5V。
拔掉 USB 線（改用電池）時這隻腳就沒電。所以不能用它餵 ESP32-C3，不然基地台一拔線 C3 就死。
→ 請用 3V3 腳。
坑 2：「BAT」腳是電池的原始電壓（最高 4.2V）。
千萬不要把它接到任何 3.3V 的輸入腳，會燒。
（板子內部有分壓到 GP26/BAT_ADC 做電量偵測，要看電量請讀 GP26，不要去碰 BAT。）
坑 3：ESP32-C3 SuperMini 的「3V3」腳是它自己 LDO 的輸出。
從外面回灌 3.3V 實務上可行（LDO 閒置），但那不是正統做法。
要講究的話改用裸模組 ESP32-C3-MINI-1，直接吃 3.3V，體積也更小、更省電。

⑤ 續航估算（基地台不像項圈那麼吃緊）

狀態電流2000mAh 電池
待機（AMOLED 關閉、C3 modem-sleep）約 15–25 mA4–5 天
使用中（螢幕全亮＋BLE 連線）約 120–160 mA約 12–16 小時

AMOLED 是最大消耗。因為是放在桌上的基地台，建議直接插 USB-C 常供電，電池只當停電備援。

⑦ 韌體分工

ESP32-C3（無線橋）

  • BLE server，等項圈連上來（Nordic UART Service 或自訂 GATT）
  • 收到事件 → 用 UART 丟一行 JSON 給 RP2350：{"t":"event","cls":"餓","conf":0.86}
  • RP2350 下來的指令 → 轉成 BLE 寫回項圈

RP2350（基地台本體）

  • LVGL 介面：事件時間軸、每類叫聲的次數統計、電量
  • 把事件寫進 microSD（CSV，之後可以畫趨勢圖）
  • 觸控操作：靜音、調整偵測靈敏度、手動標記「這其實是撒嬌」
